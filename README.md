# مختبر الوورد — Word Lab

موقع تفاعلي لتعليم برنامج Microsoft Word باللغة العربية، من خلال محاكي يشبه نسخة Word المثبّتة على الحاسوب.

## المحتوى
مبني على «برنامج وورد — دليل التطبيق العملي» (إعداد: سارة حرب):
1. ما برنامج وورد؟ · 2. واجهة البرنامج · 3. المستند · 4. الصفحة · 5. العناصر (النص، المحتويات، الصورة، الشكل، مربع النص، WordArt، الجدول، الرأس والتذييل، رقم الصفحة، التعليق، الحواشي، التاريخ والوقت، الرمز، المعادلات).

لكل قسم: **استكشف** · **تدرّب** (شاهد/جرّب على المحاكي) · **ما الفرق؟** · **أخطاء شائعة** · **مهمة على جهازك**.

## التشغيل
افتح `index.html` في المتصفح، أو عبر GitHub Pages.
